# Lessons

Each folder is a crate: `README.md` holds the notes, `src/lib.rs` holds the exercises (`todo!()`), and the tests at the bottom of `lib.rs` define "done".

| Crate | Topic | Run |
|---|---|---|
| [`l01_basics`](l01_basics/) | Variables, types, functions, control flow | `cargo test -p l01_basics` |

New lessons get added here as you finish the previous one.
